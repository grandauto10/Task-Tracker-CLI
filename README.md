# Task Tracker CLI

A simple command-line Task Tracker application that allows you to add, update, delete, and manage your tasks directly from the terminal. Tasks are stored in a JSON file in the current directory.

---

## 📌 Features

- Add new tasks  
- List all tasks  
- List tasks by status:
  - Done
  - Not done (todo)
  - In progress
- Update a task description  
- Delete a task  
- Mark a task as done or in progress  
- Stores data in a JSON file  
- JSON file auto-creates if it doesn't exist  
- Works with positional command-line arguments  
- Uses only native Python modules (no external libraries)

---

## 🛠 Requirements

- Python 3.x
- No external dependencies
- Git (optional, for version control)
